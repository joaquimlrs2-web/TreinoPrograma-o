Integração com ChatGPT (opcional)

Se você tiver uma chave de API da OpenAI, o Luau Dojo pode gerar desafios inéditos e dar dicas personalizadas. Isso é totalmente opcional — o site funciona 100% sem isso, usando o banco de desafios embutido.

sem chave configurada

Nota: a chamada é feita direto do seu navegador para a API da OpenAI. Alguns navegadores/redes podem bloquear isso (CORS). Se der erro, sua chave pode não ter permissão para chamadas via browser — nesse caso o modo prática continua funcionando normalmente com o banco de desafios embutido.

Sobre a execução do código

Seu código é executado de verdade no navegador usando o Fengari, uma máquina virtual de Lua 5.3 escrita em JS. Luau (usado no Roblox Studio) é baseado em Lua 5.1 com várias extensões próprias, então esse ambiente cobre bem a lógica pura dos desafios (variáveis, condicionais, laços, funções, tabelas, strings, recursão), mas não simula APIs específicas do Roblox (Instance, game.Workspace, etc.) nem sintaxes exclusivas de Luau mais recentes.

Dados salvos

Tudo (biblioteca de soluções, progresso diário, sequência) fica salvo no localStorage deste navegador — não há servidor nem conta.
